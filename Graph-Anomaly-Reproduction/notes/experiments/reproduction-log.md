## 运行命令

在 WSL Ubuntu 中激活环境并进入仓库目录：

```bash
source ~/.venvs/tfgad/bin/activate
cd "/mnt/c/Users/28641/Desktop/论文科研-江权学长/Graph-Anomaly-Reproduction/Repositories/TFGAD"
export DGLBACKEND=pytorch
```

Cora（论文 Table 7 参数）：

```bash
python main.py --dataset inj_cora --k1 1 --k2 5 --eta 10
```

Reddit 仓库默认参数（仅作默认参数结果记录）：

```bash
python main.py --dataset inj_reddit --k1 1 --k2 5 --eta 10
```

Reddit（论文 Table 7 参数）：

```bash
python main.py --dataset inj_reddit --k1 10 --k2 5 --eta 500
```

- 随机种子：`main.py` 没有设置随机种子参数，也没有调用固定随机种子的代码。`torch.svd_lowrank` 使用随机化低秩分解，因此重复运行的分数末位会波动。
- `--k1` 是属性矩阵的低秩维数，`--k2` 是邻接矩阵的低秩维数，`--eta` 用于缩放结构投影分数。
- 程序的 `AUC-PR` 输出来自 scikit-learn `average_precision_score`；记录时标作 AP，并在与论文 AUC-PR 对比时注明实现口径可能不同。

## 代码阅读路线

仓库只有主要脚本 `main.py`，按执行顺序阅读：

1. `load_dataset`（第 9–24 行）：载入 DGL 图、节点特征、邻接矩阵和标签，并把邻接矩阵转换成 PyTorch 稀疏张量。
2. `main` 的数据加载与形状输出（第 27–29 行）。
3. 两次 `torch.svd_lowrank`（第 31–33 行）：分别为特征和连接结构找主要低秩方向。
4. 异常分数（第 35–37 行）：属性重建误差加上缩放后的结构投影长度。
5. 评估（第 39–41 行）：使用标签计算 ROC-AUC 与 Average Precision。
6. 命令行参数（第 45–53 行）：设定数据集、`k1`、`k2`、`eta` 的默认值，并调用 `main`。

这段实现没有神经网络训练循环、优化器或反向传播；标签只用于最后评估，不参与生成异常分数。
