# 本机实验环境配置与运行指引

盘点和配置日期：2026-10-12。原则是按方法隔离依赖，不覆盖系统 Python 或已有实验环境。

## Windows 主环境

仓库内独立环境：`.venvs/win-gad-modern`，Python 3.11.16。运行时直接调用环境解释器，避免误用系统默认 Python：

```powershell
$repo = 'C:\Users\28641\Desktop\论文科研-江权学长\Graph-Anomaly-Reproduction'
$py = "$repo\.venvs\win-gad-modern\Scripts\python.exe"
& $py --version
```

已安装并核验：

| 组件 | 版本 / 状态 |
|---|---|
| PyTorch | 2.3.1+cu121 |
| CUDA 运行库 | 12.1（由 PyTorch wheel 提供；无需安装完整 CUDA Toolkit） |
| GPU | NVIDIA GeForce RTX 4060 Laptop GPU；`torch.cuda.is_available()` 为 True |
| PyTorch Geometric | 2.6.1 |
| PyG CUDA 扩展 | pyg-lib、torch-scatter、torch-sparse、torch-cluster、torch-spline-conv 均可导入 |
| PyGOD | 1.1.0，本地仓库 editable 安装 |
| EB-GAD | 本地仓库 editable 安装 |
| NumPy / SciPy / scikit-learn | 1.26.4 / 1.16.0 / 1.7.1 |
| pandas / pyamg | 3.0.6 / 5.3.0 |

环境检查执行了依赖一致性检查、Python 包导入检查、NumPy 与 Torch 互转检查，以及向 GPU 放置小张量；**没有启动任何论文模型、数据集或 NeighborDiv 实验**。`uv pip check` 无依赖冲突。PyTorch 2.3.1 + NumPy 2 会产生 NumPy C 接口警告，所以这里将 NumPy 固定为 1.26.4；EB-GAD README 中的 NumPy 2.3.5 是其 CPU 测试版本，若要严格使用该组合应另建环境。

此环境的依赖覆盖 NeighborDiv（只具备运行依赖，尚未执行实验）、EB-GAD、PyGOD、AlignGAD、ARC-zero，以及基于 PyGOD 的 DOMINANT 对照。使用任一仓库时先进入该仓库目录，再用 `$py` 执行其 README 指定的脚本。例如：

```powershell
Set-Location "$repo\Repositories\EBGAD"
& $py .\run_ebgad.py --help
```

上述 `--help` 只是脚本参数查询；实际实验需另按对应论文的数据和参数运行。不要用 Windows 全局 `python` 代替 `$py`：当前全局默认 Python 是 3.13，里面的 PyTorch 2.12.0 是 CPU 版。

主环境完整依赖快照保存在 [`windows-gad-modern-lock.txt`](windows-gad-modern-lock.txt)。

## 基础工具盘点

- Windows Python：默认 Python 3.13.7；另有 uv 管理的 Python 3.11.16，已用于本仓库主环境。Python 3.12 启动器登记路径已失效，不使用。
- `uv`：0.12.5；`git`：2.55.0；Node.js：24.18.0；npm：11.13.0。
- NVIDIA 驱动：566.07；`nvidia-smi` 报告 CUDA 12.7 兼容能力。没有安装 `nvcc` / 完整 CUDA Toolkit；使用预编译 PyTorch wheel 做实验不需要本机编译 CUDA 扩展。
- Node.js 对这些 Python 图异常检测仓库不是必需依赖，但已安装可供其他工具使用。
- Windows 默认 Python 3.13 下现有的 PyTorch 2.12.0 是 CPU 版；图实验请使用仓库内 `.venvs/win-gad-modern`。
